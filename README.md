## &nbsp;&nbsp;◈ &nbsp;Selected Work

<br/>

**`01` &nbsp;— &nbsp;Crisis Triage Trainer** &nbsp;|&nbsp; *Multi-Agent Reinforcement Learning*

> Four emergency response agents trained with **GRPO** via `trl` + `unsloth` on Qwen2.5, learning to coordinate in real-time crisis scenarios. Deployed on a HuggingFace Docker Space backed by an **A10G GPU**. Each agent operates on independent reward signals yet achieves emergent cooperative behavior.

`PyTorch` &nbsp;`TRL` &nbsp;`Unsloth` &nbsp;`Qwen2.5` &nbsp;`HuggingFace Spaces` &nbsp;`Multi-Agent RL` &nbsp;`GRPO`

---

**`02` &nbsp;— &nbsp;Multi-Agent Productivity Assistant** &nbsp;|&nbsp; *Orchestrator Architecture*

> An orchestrator that intelligently routes user intent to specialized sub-agents — **Task**, **Calendar**, and **Notes** — using dynamic intent parsing. Designed for modularity: new agents can be plugged in without touching the core routing logic.

`Python` &nbsp;`LLM Agents` &nbsp;`Orchestration` &nbsp;`Intent Parsing`

---

**`03` &nbsp;— &nbsp;AI Autonomous Driving Simulator** &nbsp;|&nbsp; *Computer Vision + Deep Learning*

> Neural network-driven car simulation combining **CNNs**, **OpenCV**, and LiDAR concepts within the **CARLA** simulator. Uses a hybrid architecture — ML model drives decisions while deterministic safety rules handle edge-case overrides.

`PyTorch` &nbsp;`CARLA` &nbsp;`OpenCV` &nbsp;`CNNs` &nbsp;`Hybrid Decision Logic`

---

**`04` &nbsp;— &nbsp;Java Backend Systems** &nbsp;|&nbsp; *Production-Grade APIs*

> End-to-end REST APIs built on **Spring Boot** + **Oracle DB** + **JDBC** — from schema design to API layer to frontend integration. Emphasizes clean architecture, real-world design patterns, and production readiness.

`Java` &nbsp;`Spring Boot` &nbsp;`Oracle DB` &nbsp;`JDBC` &nbsp;`MySQL` &nbsp;`REST API`
